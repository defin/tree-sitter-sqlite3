# tree-sitter-sqlite3 — Swift binding

Add to your `Package.swift`:

```swift
.package(url: "https://github.com/defin/tree-sitter-sqlite3", from: "0.1.0"),
```

Then in your target dependencies:

```swift
.product(name: "TreeSitterSqlite3", package: "tree-sitter-sqlite3"),
```

See the repository [README](https://github.com/defin/tree-sitter-sqlite3) for full project documentation.
